## 1. The obstruction

**Setup (all independently re-verified this spike, §2).** By Labute's descent
characterization (the note's route, [Labute] Thm 4): the canonical orientation of D_R takes
generator values χ_R(s,x,y) = (S, X, Y) with

- X = the unique root in ℤ₂ of Z³ + 2Z² + 1 (Hensel at Z ≡ 1 mod 2; X ≡ 5 mod 16),
- S = −X³/(X²+X+1) ≡ 13 mod 16,   Y = −X²,

and the canonical orientation of D₀ takes generator values χ₀(A,S,Y) = (−1, 1, η),
η = (−3)⁻¹. Both descent systems have **unique** solutions (branch Y = +X² dies on
(X−1)(X²−X−1) = 0 with X²−X−1 odd, then Cy = 2 ≠ 0). f = Z³+2Z²+1 is irreducible over ℚ
(no root ±1), so K = ℚ(X) ⊂ ℚ₂ is a cubic field (disc −59); norms:
N(X) = −1, N(X²+X+1) = 4, N(S) = 1/4, N(Y) = −1, N(η) = −1/27.

**Step 1: one word-epi already forces an iso.** Let f : G ↠ H be a continuous epi with
G, H ∈ {D₀, D_R} and K = ker f ≠ 1. Both groups have dim H¹(·,𝔽₂) = 3 and dim H² = 1,
so inflation is an iso on H¹; restriction H¹(G) → H¹(K)^G is then zero, so transgression is
injective on H¹(K)^G ≠ 0 (K ≠ 1 pro-2, plus the 2-power-orbit fixed-point argument), so it
hits the generator of H²(H) ≅ 𝔽₂ and exactness kills inf : H²(H) → H²(G). But then the
entire cup form of G factors as inf∘(cup of H) = 0, contradicting s*∪x* = 1 (D_R) resp.
S*∪Y* = 1 (D₀). So K = 1: **any epi between D₀ and D_R (either direction) is an iso.**
In particular certificates (2)+(3) in even ONE direction already produce an iso whose
generator images are finite words.

**Step 2: isos intertwine canonical orientations.** The dualizing module is unique and its
character is literal (Aut(ℤ₂) is central), so χ_R ∘ φ = χ₀ for any continuous iso
φ : D₀ → D_R, and χ₀ ∘ ψ = χ_R dually.

**Step 3: norm/rationality contradiction.**
*Forward.* If φY is a word in s,x,y with exponent sums (e,m,n) then
χ_R(φY) = S^e X^m Y^n ∈ K^×, and N_{K/ℚ}(S^e X^m Y^n) = (1/4)^e(−1)^{m+n}, of 3-adic
valuation 0. But Step 2 forces χ_R(φY) = χ₀(Y) = η with N(η) = −1/27, 3-adic valuation −3.
(Equality of elements of K inside ℚ₂ is equality in K.) Impossible — for **any** integers,
ν-marked or not. Under the ν-marking the other two images die too: φS needs
S¹X^mY^n = 1, norm 4⁻¹ ≠ ±1; φA needs S⁻²X^mY^n = −1, norm 16 ≠ ±1.
*Reverse.* χ₀ on any word in A,S,Y takes values (−1)^a η^c ∈ ℚ; but χ₀(ψx) must equal
X ∉ ℚ (and χ₀(ψs) = S, χ₀(ψy) = Y likewise cubic irrationals). All three images impossible.

Hence no certificate pair — indeed no single direction — exists. ∎

**Sanity check on the method — the in-tree precedent passes.** Running the same descent
computation on `DyadicNielsen.lean`'s Π = ⟨σ,x₀,x₁ | x₀^{σ²}·x₀·[x₁,σ]⟩ gives
χ_Π(σ,x₀,x₁) = (1,−1,η) — exactly the values predicted by the known words
σ↦S, x₀↦S⁻²A⁻¹, x₁↦Y (i.e. (1, 1⁻²(−1)⁻¹, η)). There the obstruction test passes because
all values lie in ⟨−1, η⟩ with *integer* exponents; `d0PiEquiv` exists precisely because
Π's orientation values are in the rational monomial span of D₀'s. For D_R they are cubic
irrationals: this is the invariant that separates the two situations, and a cheap
**necessary precondition to run before any future Nielsen-spike ticket**.

**Multiplicative structure for the record.** The full relation lattice of (S,X,Y) in ℤ₂ˣ is
generated by Y² = X⁴ (= the character relation, as it must be); the word-value group is
U = ⟨S⟩ × ⟨X⟩ × ⟨−1⟩ ≅ ℤ² × C₂, and η ∉ U.

## 3. Can Route N be repaired? (checked, no)

- **Different target model with in-tree identification** (Π instead of D₀): ψ-direction
  needs χ_Π-word values (rational, ±η^ℤ) to hit S, X — same irrationality kill.
- **Words with ℤ₂-exponent letters** (`zpowZtwo`, e.g. adjoin x^μ with X^μ = η): the
  χ-obstruction vanishes (the closed subgroup generated is all of {±1}×(1+4ℤ₂)), but
  certificates stop being discrete-free-group identities: the ambient object acquires
  relations (x commutes with x^μ), membership ledgers need convergence arguments, and the
  Labute successive approximation gives no reason for a finite ledger to exist at any
  finite alphabet. This is Route L in disguise with worse ergonomics — not recommended.
- **Words at the 4-generator Γ_R level**: in any pro-2 target τ dies and ω₂-powers are
  identities, so such words factor through words in s,x,y — same obstruction.
- **Both-maps-non-epi variants**: Hopfian needs ψ∘φ epi, which forces ψ epi, which by
  Step 1 is an iso — dead as above.
