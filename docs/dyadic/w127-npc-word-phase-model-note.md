# W127: twisted-head Gauss model for arbitrary-unit Npc

The arbitrary unit in the procyclic-N row changes both the quadratic head and its cross operator;
it is not a removable affine linear shift.  After inverting the cross operator, the correct model
is a twisted `plusFormD d0 q` head followed by the standard hyperbolic handle planes.

For every quadratic `d0`, this model has the required positive standard ramified Gauss value.  A
generic phase-model predicate and reduction now turn one per-boundary source comparison into the
full branch-free word-phase supply.

The comparison itself remains open only on the unramified full-offset Hessian: `evenPhiNormal`
has `x2 = Phi x0`, while the existing Npc Hessian theorem assumes `x2 = 0`.  All four exported
declarations use exactly the standard three axioms.
