# W181: the absolute residue exact sequence needs one Frobenius lift

W180 characterized surjectivity of the canonical absolute residue action by compatible lifts at
every finite normal residue level. W181 proves that this entire family of lifts is equivalent to
one element.

The new module
`GQ2/Dyadic/Instances/RamifiedCertificateAbsoluteResidueFrobeniusLift.lean` defines
`AbsoluteResidueFrobeniusLift`: an absolute Galois element whose residue action is the square
Frobenius. If such an element exists, its powers lift every automorphism of every finite normal
residue subfield because finite-field Galois groups are generated by Frobenius. Compact closedness
from W180 then gives full residue-action surjectivity. Conversely, surjectivity supplies the
Frobenius element immediately.

The same condition has a concrete Teichmuller formulation. `SquaresOddRootsOfUnity g` says that
`g` squares every root of unity of odd order. Odd-order Teichmuller approximation detects every
nonzero residue class, and odd-root separation turns equality of reductions back into equality of
roots. Hence:

```text
residue action surjective
  iff one absolute square-Frobenius lift exists
  iff one absolute Galois element squares every odd-order root of unity.
```

All declarations use only `propext`, `Classical.choice`, and `Quot.sound`. No existence assertion
for the Frobenius element is smuggled in.

The exact residue-side field input is now a single classical statement: construct an absolute
Galois element that squares all prime-to-two roots of unity. After that, the remaining topological
work is the normalized continuous Frobenius coordinate on the residue Galois group and its
commuting square with the oriented tame quotient. The anchored norm-value front is unchanged.
