Date: 2026-08-16

## Result

`GQ2/Dyadic/Instances/MpcMarkedSupply.lean` installs the full four-slot marked-move API for

claiming the missing all-class supply theorem.

## Construction

The earlier two-slot marked producer changes only the `Bbar` and `Dbar` corrections.  The
exact ladder increment has two additional correction slots, and the class-four witness
already needs a head move.  The new API therefore lets all four slots move:

* the head, `Bbar`, and `Dbar` slots lie in `mpcSxKill j`;
* the pivot slot lies in `mpcMkPivotKill j`, the intersection of the `j`th central layer
  with the subgroup generated by commutators.

The commutator-generated pivot carrier is chi-trivial and invisible to every continuous
`Multiplicative Z2` character.  It is therefore contained in `mpcWordCorrC` at the required
depth.  A full marked move consequently gives an ordinary `MpcLadMove`, and full marked
supply gives the existing `MpcLadSupply`.

The module proves that full marked supply at every `j >= 3` implies `MpcPivShift 2`.  It
also packages the already-proved class-five step as the concrete `j = 3` witness in exactly
the quantifier shape required by that conditional endpoint.

## Exact remaining theorem

The unproved content is now isolated: for every `j >= 4`, a class-`(j+1)` solution must
have its top-layer defect in the image of the full marked cost map.  W94's subsequent exact
class-six calculation shows that this image has corank five and contains the actual defect.
It therefore rules out the initially suggested blanket containment of a codimension-one
chi-twisted Fox kernel.  The uniform theorem must target the M6 defect family more narrowly
or enlarge the correction carriers.

The repository has the exact increment formula and generic layer calculus, but it does not
yet contain this graded/Fox exactness theorem for `D_M 2 0`.  The earlier Fox-ideal
calculation is campaign prose rather than a formal result.  Thus this wave advances the
positive route and falsifies any accidental two-slot restriction, but does not present a
conditional theorem as the finished M6 selector.
