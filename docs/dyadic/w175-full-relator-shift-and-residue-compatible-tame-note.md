# W175: full-relator shift and residue-compatible tame data

W175 sharpens the two structural boundaries left by W174.  It does not add an analytic,
determinant, or corrected-RN premise.

## General-h Mpc shift

`MpcGeneralHandleShiftRecipe` proves that the correction monoid generated by the landed handle
Eichler moves, handle mixes, and M5 corrections fixes the distinguished `C` generator literally.
The mod-two `B`-coordinate detector then shows that no element of this monoid has the required
odd `C + 2B` row.  Consequently every `MpcPivShiftH` witness lies outside the existing correction
closure; scaling and handle clearing cannot synthesize the missing shift.

The same module proves `mpcPivShiftH_iff_marking`: the general shift is equivalent to a full
`4 + 2*h`-letter, relator-killing, topologically generating, chi-oriented marking.  Thus the
remaining general-h Mpc theorem is exactly a new all-letter relator marking/ladder theorem, not a
missing adapter around the rank-four construction.

## Residue-compatible oriented tame quotients

`RamifiedCertificateResidueCompatibleOrientedTame` defines
`AbsoluteResidueCompatibleOrientedTameQuotientK`.  It extends the existing oriented tame quotient
by precisely `OrientedFullTameInertiaLiesInAbsoluteInertiaAt`: the preimage of abstract full tame
inertia lies in the kernel of the canonical absolute residue action.

That single comparison produces `CompatibleResidueLiftAt` at every transported parameter set.
Together with the already isolated anchored involution-field packet—or with its equal-norm-value
form—it produces `CompatibleRamifiedDataAt` and the compatible odd-degree gamma equivalence.
Nothing in the existing `OrientedTameQuotientK` proves the added field: AX4 controls only the
2-primary unramified coordinate and contains no comparison with the valuation-theoretic residue
action.
