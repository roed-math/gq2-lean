# W289: the class-seven neutral rank jump

W288 reduced full W6 correctability to equality of two finite transpose kernels. W289 turns
that equality into a single rank comparison over `F₂`.

The unaugmented transpose rank is `oneHandleCompactNeutralImageTransposeRank`; adjoining a
chosen neutral obstruction gives `oneHandleCompactNeutralTargetAugmentedTransposeRank`. The
augmented rank is either unchanged or exactly one larger. For the obstruction attached to any
ordinary correction, equality is exactly full W6 correctability.

Equivalently, failure is a one-bit rank jump and is witnessed by a character annihilating the
neutral connecting image while detecting the target. The remaining campaign task is now the
concrete evaluation of this finite rank bit; no rank value is asserted here.
