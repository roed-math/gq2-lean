# W272 — the class-seven ordinary-relative rank jump

W271 turns ordinary relative coverage into equality of the coordinate and augmented
`ZMod 2` ranks.  The augmented image projects onto the coordinate image and embeds into the
coordinate image times one copy of `ZMod 2`.  Its rank therefore has exactly two possible
values: the coordinate rank or the coordinate rank plus one.

The two cases now have exact meanings:

* rank jump zero is ordinary relative coverage;
* rank jump one is failure, witnessed by a functional which kills all four standard rows but
  evaluates nontrivially on the selected class-seven target.

There is no larger-rank failure mode.  This wave proves the dichotomy but does not decide its
side.  The next calculation must rule out the detecting functional, or construct the target
row from the four coordinate rows.  The character-neutral `C` quotient remains a separate
second obstruction after the zero-jump case.
