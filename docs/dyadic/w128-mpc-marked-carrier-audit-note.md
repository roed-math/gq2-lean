# W128: marked-carrier density and congruence

The routine carrier issues in the uniform Mpc successor are now closed.

- The pivot carrier is exactly the ordinary commutator subgroup.
- The free-slot carrier is the inverse image of the line generated by the class of `B^2` in the
  ordinary abelianization.
- Elements in the corresponding topological closures can be rounded to actual carrier elements
  modulo the next filtration rung.
- Such rounding does not change the top cost class.

The sole remaining theorem is therefore algebraic graded exactness:

`ker ((nu, chi) o c_r) = M_r + ker c_r`.

It is documented but not assumed.  All seven exported declarations use exactly the standard
three axioms.
