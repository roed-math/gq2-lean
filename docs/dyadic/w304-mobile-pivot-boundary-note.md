# W304: the coordinate-free M-family pivot boundary

W304 sharpens W303's all-degree campaign boundary without splitting by nilpotency class.
For every canonical selected M0 or Mpc row, it proves that an exact-level value already exists
somewhere in the cyclotomic kernel.  This coordinate-free condition is

`MFieldMobilePivotAtLevel B alpha r h`.

The result follows from the field's actual cyclotomic range.  At level zero the existing
chi-kernel unimodularity theorem supplies a unit value; at positive level the exact-kernel
value theorem supplies a value equal to `2^r`.  Thus failure of W303's distinguished-C
condition can no longer be described as a missing value or a missing level theorem.

`MFieldPivotPlacementDefect` records the remaining issue exactly: a mobile exact-level value
exists, but no oriented canonical M presentation places such a value on `C`.  Under the now
proved mobile-pivot boundary, the distinguished-C condition is equivalent to absence of this
placement defect.

The general campaign front is therefore a normal-form question, common to M0 and
epsilon-false Mpc in every degree and handle count.  One must either move the mobile value to
the distinguished coordinate while preserving the presentation, or introduce an alternate M
normal form centered at the coordinate that actually carries the value.  No further
class-by-class computation is implicated by this reduction.
