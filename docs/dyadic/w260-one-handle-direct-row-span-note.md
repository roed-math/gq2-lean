# W260 — one-handle direct target row span

The zero-rank-jump criterion is now an explicit row-span criterion.  The target-evaluation
functional belongs to the span of the four coordinate-row families exactly when it factors
through the coordinate transpose.  A factor on the coordinate image extends over `F₂` to
the full coordinate target.

Target-row factorization, existence of a direct correction, and zero finrank jump are
equivalent.  The dual obstruction is exactly failure of row-span membership.  The remaining
task is therefore one explicit finite linear dependence theorem; this wave does not assert it.
