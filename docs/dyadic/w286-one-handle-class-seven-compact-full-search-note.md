# W286: explicit finite class-seven search sets

W285 proved that a finite proof-carrying solution type is nonempty exactly when W6 is
correctable.  W286 exposes the underlying kernel corrections as ordinary finite sets.

`compactConnectingFiber E` contains exactly the compact-kernel corrections mapping to the
reference ordinary obstruction.  Its nonemptiness is ordinary relative solvability.
`compactFullCorrectionCandidates E` filters those corrections by the neutral-C obstruction
of their canonical realized lifts.  Its nonemptiness is exactly full W6 correctability, and it
is a subset of the connecting fiber.

The campaign's one-handle class-seven problem is consequently an explicit two-stage finite
search: solve one linear connecting-image equation, then test one finite neutrality equation
on that fiber.  No inverse-limit or representative-realization premise remains.
