# W259 — one-handle direct rank jump

The target-augmented transpose appends one `ZMod 2` row to the four coordinate rows.  Its
image projects onto the coordinate image and embeds into the coordinate image times
`ZMod 2`.  Therefore its finrank is either the coordinate finrank or exactly one larger.

A direct correction exists exactly in the zero-jump case.  The dual target obstruction is
exactly the one-dimensional-jump case.  This sharpens the remaining one-handle problem to
deciding whether the appended target row is dependent on the four coordinate rows; it does
not assert that dependence.
