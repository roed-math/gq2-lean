# W262 — selectable one-handle direct correction

The earlier direct interfaces required every point of every nonempty stage to admit a
correction.  The inverse-limit induction only needs one correctable point at each rung.
W262 packages this strictly weaker selectable condition and proves that it gives the direct
successor supply and `MpcPivShiftH 2 1`.

Selectable correction is equivalent both to selecting a point with zero augmented-transpose
finrank jump and to selecting a point with a four-family target-row coefficient identity.
The remaining one-handle theorem is therefore existential at each finite rung; no uniform
statement about all stage points is needed or asserted.
