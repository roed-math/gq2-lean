# W242: the nine-CABD successor criterion

W242 inserts W241's finite target checklist into the balanced one-handle successor machine.
The stage at rung `k + 1` is nonempty exactly when the stage at rung `k` contains a point whose
target has ordinary relative coverage and satisfies the three parity plus six primitive CABD
implications.

The corresponding stagewise nine-CABD selector is equivalent to the earlier abstract
coordinate-selectable supply. It therefore produces every finite balanced stage and the
one-handle pivot shift.

The remaining mathematical task is no longer an unspecified quotient or character argument:
it is to choose, at every occupied rung, a relatively covered point satisfying those nine
explicit scalar implications.
