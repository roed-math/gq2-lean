# W237: parity coverage of the selected target

W237 packages the W236 split without choosing a mod-four lift. A selected obstruction is
parity covered when one lift has parity in the interaction range; this property is proved
independent of the lift.

The parity-detected case is exactly failure of parity coverage. Thus full coordinate failure
is equivalent to either a primitive order-four detector or failure of parity coverage. Under
parity coverage, the remaining failure is equivalent to the primitive detector alone.

This isolates the genuinely higher-order front cleanly: first establish parity coverage of
the selected target, then rule out the six primitive directions.
