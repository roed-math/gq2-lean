# W240: the literal scalar CABD parity seam

W240 chooses one ordinary relative C class representing the selected neutrality obstruction
and proves that its two parity coordinates give the same character values as every other
target lift.

Parity coverage is now equivalent to three literal scalar implications. For each nonzero
character of the parity plane, if that character annihilates the C coordinate of every
homogeneous CABD relation, then it must annihilate the coordinates of the selected target C
representative.

This is the exact remaining parity calculation. It mentions neither an abstract quotient nor
an unspecified dual character. Once these three implications are proved from the graded
