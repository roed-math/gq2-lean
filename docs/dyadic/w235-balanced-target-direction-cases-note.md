# W235: nine balanced target directions

W234 expresses target detection by a nonzero dot product with a coefficient pair in
`(ZMod 4)²`. Multiplying both coefficients by a unit preserves all zero and nonzero dot
products. The fifteen nonzero pairs therefore reduce to nine exact cases.

Six cases are primitive, with at least one odd coefficient. The remaining three are the
parity directions `(2,0)`, `(0,2)`, and `(2,2)`. W235 proves this finite classification and
rewrites the target obstruction, failure of constrained coordinate coverage, and pointwise
next-stage emptiness using precisely these nine directions.

This separates genuinely order-four obstructions from parity obstructions. It is an exact
case split, not a proof that any of the nine directions detects a target.
