# W294: maximal neutral-image rank closes class seven

The earlier rank-two criterion used only the coarse fact that the neutral target has dimension
at most two.  W294 replaces it by the sharp statement: if the compact neutral-image transpose
has the same rank as the actual standard neutral target, then the transpose is injective and
every neutral obstruction is in the compact connecting image.  Hence the full W6 correction
follows.

Together with W293, the remaining sufficient calculation is the exact binary rank equation

`compact-image rank + parity-interaction rank = 2`.

Neither summand is computed here.  The theorem isolates the finite equality whose proof would
close the class-seven correction.
