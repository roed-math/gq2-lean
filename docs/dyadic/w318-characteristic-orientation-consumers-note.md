# W318: general characteristic-orientation consumers

W318 removes the now-proved `MCoreOrientationCharacteristic` premise from the
uniform compact-M and arbitrary-display Mpc realized-certificate consumers.

Given one oriented field equivalence, every realized `WordCertificateRN` now forces
the canonical distinguished-C pivot at every depth and handle count.  The same is
packaged for the existential realized-certificate records, and the strict-handle
incompatibility theorem no longer carries an orientation hypothesis.

This is deliberately not a circular producer of a field realization: it proves that
any successful realized certificate must already have the canonical pivot.  Thus the
remaining general M-family issue is the existence/normalization of that field marking,
not orientation naturality and not a class-specific analytic calculation.

All five public declarations use exactly
`[propext, Classical.choice, Quot.sound]`.
