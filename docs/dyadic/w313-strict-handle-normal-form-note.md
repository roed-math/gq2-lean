# W313: the remaining M handle form is strict

W313 sharpens the common handle boundary.  The level condition already makes C divisible by
`2^r`.  If C is not itself an exact level-r pivot, its quotient is a nonunit in `Ztwo`, hence
even.  Therefore C is divisible by `2^(r+1)`.

Every selected compact-M or epsilon-false procyclic-M row now has either the canonical exact C
pivot or this strict alternate form:

- one chosen handle U row is exactly `2^r`;
- its paired V row is zero;
- the C row lies at least one level deeper.

`StrictNormalizedMHandleResidualSupply` is consequently the sharp remaining even-family
interface.  Once supplied, the all-degree dispatcher produces the corrected RN residual for
every branch selected from the actual cyclotomic range.  The problem is uniform in alpha,
level, and handle count; no nilpotency class remains in the statement.
