# W271 — the class-seven ordinary-relative rank test

W270 expresses ordinary relative coverage by vanishing of the selected target on the kernel
of a four-row transpose.  W271 appends target evaluation as a fifth row.  The augmented
kernel is contained in the coordinate kernel, and finite elementary duality identifies
target coverage with equality of those two kernels.

The same condition has two concrete finite formulations.  It is equivalent to equality of
the two image cardinalities and, after viewing the images as `ZMod 2` modules, to

```text
rank(ordinary rows + target row) = rank(ordinary rows).
```

Thus the first W269 obstruction is exactly the absence of a one-bit rank jump.  No equality
is asserted in this wave: the remaining calculation is to determine whether the target row
lies in the span of the four standard rows.  Even after that succeeds, the separate
character-neutral `C` quotient from W269 still has to vanish.
