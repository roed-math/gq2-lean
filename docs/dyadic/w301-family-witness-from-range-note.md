# W301: the corrected family witness from the actual range

W301 closes the residual classification packet in the corrected family selector.  The result is
uniform in degree, marked level, and handle count; no presentation class is enumerated.

The new continuity theorem
`fieldMarkedPair_lambda_continuous` descends continuity of the field's reduced unramified
coordinate through the compact Hausdorff cyclotomic quotient.  It has two consequences.

* If the actual cyclotomic image is `imChiN alpha`, its canonical generator is dense.  A
  continuous map from that dense cyclic subgroup into the finite marked quotient has cyclic
  image, producing `procyclicMarkedGeneratorData_of_range_eq_imChiN`.
* If the image is `imChiM alpha`, the closed subgroup generated by `mUnit alpha` is exactly the
  depth-`alpha` principal-unit factor.  Every element is in this factor or its `-1` coset, and
  the factor is trivial modulo four.  This produces
  `markedGeneratorData_of_range_eq_imChiM`.

The general range dichotomy can therefore construct the even-degree witness directly:
`evenDegreeFamilyFieldBranchWitness`.  Combining it with the existing odd-degree L theorem gives
`fieldFamilyWitnessFromRange` and the caller-free selector
`selectFieldBranchFamilyFromRange`.

All six public declarations use only `propext`, `Classical.choice`, and `Quot.sound`.  In
particular, `FamilyFieldBranchWitness` is no longer a mathematical input to the all-degree field
selection.  The remaining campaign work is downstream: consume this canonical selection in a
single branch dispatcher, while keeping the genuine branch-specific arithmetic boundaries
(notably M0 pivot placement and the epsilon-false positive-level Mpc digit) explicit.
