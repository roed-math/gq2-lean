# W241: the nine scalar CABD checklist

W241 gives the six primitive order-four directions the same target-sensitive treatment as
the three parity directions from W240.

For each primitive coefficient pair, if its ZMod 4 dot product annihilates the C coordinates
of every homogeneous CABD relation, it must annihilate the selected target coordinates.
Failure of one of these six implications is exactly primitive target detection.

Combining W240 and W241, selected-target membership in the correction span is equivalent to
nine finite scalar implications: three mod-two parity cases and six primitive mod-four cases.
This is the complete finite graded checklist for the balanced successor step.
