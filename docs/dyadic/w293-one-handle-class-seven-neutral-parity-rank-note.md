# W293: class-seven neutral parity ranks

W292 identified the standard class-seven neutral target as the quotient of a two-dimensional
parity plane by the standard parity-interaction range.  W293 converts that exact quotient into
the dimension formula

`neutral target rank + parity interaction rank = 2`.

It also sharpens the previous coarse bound on the compact neutral-image transpose: its rank is
bounded by the actual neutral-target rank, not merely by two.  Thus the remaining finite
calculation is explicitly split between the standard parity row and the compact connecting
image.  This wave does not assign a value to either rank.
