# W361: exact bounded word-display abbreviations

## Defect and scope

The first combined packet PDF reported four overfull word-expression lines,
roughly 1,536–2,270 points wider than the page. Repetition-only subtree sharing
left a large unique final expression inline. Scaling such a line was not a
legible publication solution.

The revised `scripts/w361_general_word_tex.py` changes **only the display plan**.
It does not change the Lean word, serialized AST, schema, structural parameters,
continuous-parameter binding, or template hash. It performs no algebraic
simplification: identities, inverses, conjugations and powers remain literal.

## Deterministic exact DAG

The planner visits the original tree in fixed child-order postorder. Equal
subtrees are interned by their canonical JSON. It assigns a `W_i` name either
to a repeated nontrivial subtree or whenever the current display would reach
six visible tree/reference nodes. Since a word constructor has at most two
children, every emitted definition has at most eleven visible nodes. The final
expression has fewer than six nodes. Definitions use only strictly earlier
names.

An executable replay expands these display-only references. Before rendering,
the script verifies that the resulting canonical JSON is exactly the original
hashed tree and that the inline bound holds. References are not accepted as
constructors in the hashed word grammar. The emitted TeX uses blocks of at most
ten definition rows, so a caller need not enable global display-page breaking.

The bound is structural, not a promise that an arbitrarily long exact integer
literal or identifier fits any font/page setting. Such atoms are never
truncated. Physical PDF layout is verified separately by the packet owner.

## Durable regression checks

The existing schema tests now run together with 105 display-plan checks, for
142 tests total. The new tests include:

* exact expansion for a large nonrepeated chain, a deeply shared tree, every
  word constructor, and all four actual Lean-exported staged fixtures;
* strict backward references, rejection of self/forward/invalid references,
  and rejection of an altered expansion;
* the eleven-node bound and alternative limits 3, 4, 7 and 12;
* determinism under fresh copies and canonical JSON round-tripping;
* unchanged input trees and envelopes, and at most ten rows per TeX block.

The actual fixture display metrics are:

| Fixture | Definitions | Maximum inline nodes | Maximum RHS TeX characters |
| --- | ---: | ---: | ---: |
| mobile alpha2/r1/p0/h0 | 87 | 10 | 121 |
| mobile alpha3/r2/p2/h1 | 102 | 10 | 143 |
| pair alpha2/h1/j0 | 76 | 9 | 117 |
| pair alpha3/h2/j1 | 82 | 10 | 143 |

Each final displayed source word is one reference to its last definition.
