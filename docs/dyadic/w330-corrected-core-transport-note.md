# W330: corrected core transport

The general flexible route must be able to change the marked pro-2 core as well as the source
word.  W330 supplies that missing structural operation for corrected RN certificates.

`genCert_exactLiftingSemanticsRN_pull` transports the corrected exact-lifting clause across any
continuous core equivalence which respects the `Z₂` marking.  The extra corrected coefficient is
core-independent, so the frozen pullback argument applies without a new analytic premise.

`WordCertificateRN.genCertTransportRN` packages the result at certificate level.  It transports
the pro-2 map, kernel, surjectivity, compatibility, exact lifting, Stokes, scalar, and determinant
data.  Consequently a mobile-pivot-adapted core does not need a second analytic campaign: it only
needs a marking-compatible equivalence from a certified reference core.

Both public declarations print exactly the standard trust base
`[propext, Classical.choice, Quot.sound]`.
