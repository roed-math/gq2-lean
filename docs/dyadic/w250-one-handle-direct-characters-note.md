# W250: character detection of the direct obstruction

W250 applies finite Pontryagin duality to the W249 cokernel.  The direct obstruction is
trivial exactly when every additive complex character evaluates to one on it.  By the W247
range equivalence, this is exactly existence of a direct group-level correction.

The complementary statement is equally sharp: no correction exists exactly when some
character detects the obstruction.  Uniform target-character vanishing is equivalent to the
W246 correction supply and therefore implies `MpcPivShiftH 2 1`.

This is a scalar dual reformulation rather than a vanishing theorem.  A positive proof must
annihilate the selected obstruction against every finite character; a negative proof must
construct one detecting character.
