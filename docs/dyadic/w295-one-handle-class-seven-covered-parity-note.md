# W295: the parity plane covered by compact corrections

W295 pulls the compact neutral connecting range back through the standard parity factor.  This
defines `oneHandleC7StandardCoveredParity`, a concrete subgroup of `(ZMod 2)^2`.

The following conditions are equivalent:

- the covered-parity subgroup is the whole plane;
- the compact neutral connecting map is surjective;
- the compact-image rank plus the standard parity-interaction rank is two.

Any of these conditions gives the full W6 correction.  The remaining class-seven calculation
is therefore the explicit spanning statement
`oneHandleC7StandardCoveredParity = top`; no infinite or topological premise remains hidden in
that formulation.
