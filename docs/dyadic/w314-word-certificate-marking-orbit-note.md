# W314: a corrected word certificate fixes the marking orbit

W314 proves a general profinite first-isomorphism principle: two continuous epimorphisms with
the same kernel differ by a continuous automorphism of their common target.  Consequently,
two corrected word certificates for the same word and pro-2 core have markings in one
continuous automorphism orbit.

For compact M, every corrected certificate marking is therefore in the orbit of the canonical
marking.  If the M orientation is characteristic, the distinguished C parity is invariant on
that orbit.  A strict handle marking has even C and so cannot support the current compact-M
word certificate.

This rules out a misleading shortcut in the general campaign.  W313's strict handle case is
not closed by renaming coordinates in the existing certificate.  One must either construct a
genuinely different presentation compatible with that marking or prove arithmetically that
the strict handle alternative cannot occur.  The result is uniform in alpha and handle count.
