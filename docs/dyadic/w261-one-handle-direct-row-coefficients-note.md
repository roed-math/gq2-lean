# W261 — one-handle direct row coefficients

The direct target-row span condition is now an explicit four-family scalar identity.  Its
unknowns are one bidual coefficient for each of the `A`, `B`, `C`, and `D` coordinate-row
families.  Every abstract row-span factor splits into these four coefficients, and the four
coefficients recombine into a factor on the full coordinate target.

Existence of the coefficient tuple, target-row membership, direct correction, and zero
finrank jump are equivalent.  The coefficient spaces are finite, so this is a direct finite
search certificate.  No coefficient tuple is asserted in this wave.
