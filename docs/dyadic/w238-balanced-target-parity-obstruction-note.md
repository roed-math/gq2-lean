# W238: the canonical parity obstruction

W238 replaces the existential parity-coverage condition by a canonical finite quotient class.
For any mod-four lift of the selected neutrality obstruction, reduce its two coordinates mod
two and then quotient by the parity interaction range. All lifts give the same class.

The selected target is parity covered exactly when this class is trivial. Consequently the
parity-detected branch is exactly nontriviality of the canonical class, and full coordinate
failure is equivalent to either a primitive order-four detector or a nontrivial parity
obstruction.

The remaining balanced one-handle front is therefore explicit: prove that canonical parity
class vanishes, then eliminate the six primitive mod-four directions.
