**Brief correction 1.**  The brief expected "chi_sq(x1) = -1 and chi_sq(x0) of
infinite order".  The second half is right, the first is false at the letter level:
no generator value is `-1`.  The torsion enters as `Y * X^{-2} = -1`
(`YvalUnit_eq_neg_sq`; on the rank-3 core this is the committed `chiR_torsion`).

**The invariant.**  `Im(chi_sq)` is the closed subgroup generated by `S, X, Y`.
`X` has `v2(X-1) = 2` exactly, so its closure is `U2^(2) = 1 + 4Z2`; `-1 = Y X^{-2}`
is in the image; and `S = -X^3 (X^2+X+1)^{-1}` lies in the closure of `<-1, X>`.
Hence `Im(chi_sq) = {±1} × U2^(2)`, which **is all of** `Z2^x` (every 2-adic unit is
`±1 mod 4`); the tree already records surjectivity as `chiSq_surjective`
(`PivotClimb` §7).  So the invariant has Labute's shape `{±1} × U2^(f)` with
`f = 2`, as the brief expected.

**Brief correction 2 (which section applies).**  `sqRank h = 3 + 2h` is **odd**, and
`q = 2` (abelianized relation `rho = -4 x0bar + 2 x1bar`, `sqRelWord_comm`, torsion
`Z/2`).  Labute's §4, including §4.1/§4.2 and Lemmas 3-4 as printed, is the case
`q = 2, n even` (p. 121, section header).  The sq core is the case `q = 2, n odd`,
which Labute declares "entirely analogous" (p. 119, referring to his memoir).  So
the brief's dichotomy "§4.1 vs §4.2" does not apply verbatim; what transports is the
mechanism, and at the level of the invariant the sq core matches the §4.2 shape
`Im chi = {±1} × U2^(f)`, `f = 2`.

**The excluded column.**  Labute's tower formula `Delta_i(pi^{j-1} xi_k) = pi^j
delta_ik` carries the side condition `k ≠ 2`, excluding the one basis letter with
`chi ≡ 3 (mod 4)`.  In the campaign basis that letter is `x1`: `Y ≡ 7 ≡ 3 (mod 4)`,
while `S ≡ 13 ≡ 1` and `X ≡ 5 ≡ 1 (mod 4)` and handles have `chi = 1`.  The
mechanism: `D(x^{2^m}) = (1 + chi(x) + ... + chi(x)^{2^m - 1}) D(x)`, and the
geometric sum has 2-valuation exactly `m` when `chi(x) ≡ 1 (mod 4)` but valuation
`m + 2` for `chi(x) = Y` (since `v2(Y^2 - 1) = 4`).  The x1 tower is invisible to
every functional; every other tower is detected on the nose.  This is the
functional-side face of the wave-70/73 finding that the `x1`-slot square knob is
the delicate direction.

### 1.2  The campaign's rows versus Labute's functionals

**Brief correction 3.**  `cfourKnob_sq_nu` and `cfourKnob_sq_nuLam`
(`GradedClassFourKnob.lean:145,150`) are not row functionals; they are lemmas
("an exactly row-trivial element has an exactly row-trivial square").  The committed
row objects are the markings themselves:

* `nuLam h` (`HandleMixFixesCore.lean:234`): the chi-exponent row `lambda` with
  generator values `(c0, 1, 2)` and `0` on handles, characterized by
  `chiSq^2 = X^{2 lambda}` (`chiSq_sq_eq_lam`);
* the selected markings `nu'` (variables, pinned by `nu'(sigma) = 1, nu'(x0) = 0`);
* `nuSq` (`Cores.lean:486`, row `(1,0,0;0)`) and `nuWitness`
  (`HandleMixFixesCore.lean:197`, row `(c0,1,2;1,0)`).

All of these are **plain** continuous homs `DSq h -> Multiplicative Z2`, i.e.
crossed homomorphisms for the **trivial** character.  A plain hom must kill the
relator, so its row `a` obeys `-4 a(x0) + 2 a(x1) = 0`; the untwisted row lattice
has corank 1 and contains **no** `x1`-row (`a(x1)` is forced even).  That is the
mod-2 shadow of the `k ≠ 2` exclusion of 1.1, and it is the exact relationship:
the campaign's rows are the untwisted specializations of Labute's `D_i` for the
rows that survive untwisting; Labute's twisted `D_i` exist for **every** row.

**The true committed counterpart of Labute's D_i** is not the `nu`-rows but the
crossed-derivation calculus of `GQ2/Roe/CrossedDerivation.lean` over the lift group
`FoxH.WordLift Z2 Z2^x` (`GQ2/FoxHeisenberg/Basic.lean:76`), whose multiplication
`(u,g)(v,h) = (u + g v, gh)` **is** the crossed rule `D(xy) = Dx + chi(x) Dy`:

* `drWord_wordLift` (CrossedDerivation.lean:133): the full chi-twisted Fox row of
  the rank-3 core word, with coefficients `csR, cxR, cyR`;
* `IsLabuteOrientationDatum S X Y` (:183): "the lifted word dies for every choice of
  derivation values" - Labute's Theoreme 4 condition, and the file cites him;
* `isLabuteOrientationDatum_of_root` (:262): the datum **holds** at `(S, X, Y)`
  given the three ChiR identities; instantiated at the committed values by
  `isLabuteOrientation_chiR` (ChiR.lean:134);
* `sqWord_eq_drWord` (Cores.lean:174) is `rfl`, and the handle block dies at
  chi-trivial lifts (`handleWord_wordLift_one`, MarkedCore/Cores.lean:365).

So "every crossed homomorphism into `I(chi_sq)` kills the sq relator, at every
handle count h" is one glue lemma away from committed.  What has **never** been
committed is the promotion of this word calculus to continuous crossed
homomorphisms **on the group** `DSq h`: `WordLift` carries no topology in its
defining file, and the campaign has only ever evaluated words in it.  That
promotion is this lane's T1.

### 1.3  The twist is load-bearing (the untwisted route cannot discharge T2)

The brief suggested the layer functionals might be built untwisted ("chi ≡ 1 mod 2
... plain F2-linear functionals ... entirely at finite level with untwisted F2
coefficients").  **This is false at the strength T2 needs**, and the failure is
computable from committed lemmas.  For any hom `f : DSq h -> Multiplicative Z2`
and any tuple `m`, naturality plus the abelian collapse give the reading

    f (sqRelWord m) = (f (m 1) ^ 4)⁻¹ * (f (m 2))^2 .

At the wave-68 frame (`sqArbFrame h nu' j (bridgeTuple nu' j)`, whose class-4 class
is `cfourIdLeftover nu' j`), the slots are `m 1 = x0 * A`, `m 2 = x1` with
`A = bridgeDress nu' j = u^{nu'(v)} v^{nu'(u)} w^{-2 nu'(u) nu'(v)}`, so the reading
is `-4 f(A)` additively; for the handle row `f = e_{u_j}` (an admissible untwisted
row) this is `-4 nu'(v_j)`, which at a selected marking with `nu'(v_j)` a unit is
**not** divisible by `2^3`: the untwisted handle-row functional does not kill the
committed leftover at its own layer bit (`cfourIdLeftover` lies in
`zLayer (DSq h) 3`, where the reading precision is the `2^2` bit mod `2^3`, and
lifts move the value only by `f(lambda_4) ⊆ 2^3 Z2`).  The twist correction
`(chi(x0) - 1) D(A) = 4 * unit * D(A)` lands exactly on the layer bit; dropping it
changes the answer.  Labute's Lemma 4 uses `D` into `2I` **with** the twist, and so
must we.  (The twisted functionals do kill the leftover exactly: `chi_sq(A) = 1`
because the pivot is chi-trivial, `chiSq_sqPivot`, so the dressed frame has the
standard chi-values and the vanishing Fox row applies.  Committed as
`gDelta_leftover_lift` below.)

### 1.4  Free side versus quotient side

* `sqRelator h : FreeProfiniteGroup (Fin (sqRank h))` (Cores.lean:260) - free side.
* `DSq h = presPro2 (sqRelator h)` - the one-relator pro-2 quotient (Cores.lean:265).
* `SqClassClearingSupply h k` (GradedLimit.lean:236) is stated **on `DSq h`**:
  dressings `a : Fin (sqRank h) -> DSq h`, frame `sqArbFrame h nu' j a`
  (ArbFrames.lean:442, base `sqArbBase` with the Eichler-cleared handle letters
  `sqEichU/V`, LamFrames.lean:295,303), relator clause
  `sqRelWord (frame) ∈ twoCentralSeries (DSq h) k`.
* All wave 68-73 defect objects (`cfourEichDefect` GradedClassFour.lean:628,
  `cfourIdLeftover` GradedClassFourIdentity.lean:241, `cfourDefCore`
  GradedClassFourDefect.lean:242) live in `levelQuot (DSq h) 4 = DSq h / lambda_4`.

Labute's Lemma 4 lives on the free group `F` and uses freeness only to *prescribe*
crossed homomorphisms.  On the quotient side prescription is available iff the
twisted Fox row of the relator vanishes, which is exactly the committed datum
theorem.  So this lane states everything **directly on `DSq h`** (hence directly
against the supply's own objects), with no free-group detour: the functionals exist
on `DSq h` with arbitrary generator rows, which is strictly more than the untwisted
corank-1 lattice of 1.2 and is the correct campaign-side reading of "H^2(F) = 0
lets D descend".

### 1.5  An instance hazard, recorded

`GQ2/WordCohBridge.lean:55` globally installs `TopologicalSpace (WordLift A C) = ⊥`
(and `DiscreteTopology`) for **all** `A, C`, and that file is in the transitive
import closure of the SqCore graded modules.  The discrete topology is unusable
here (`WordLift Z2 Z2^x` must be compact for the lift through `sqLiftHom`, and
pro-2-ness fails for the discrete topology).  This lane therefore declares its
product-topology instances as **local instances (priority 2000) inside the module
only** and exports them as named defs (`gDeltaTop`, ...); exported constants bake
the correct instances into their types, so consumers never need to re-resolve them.
W75 should re-attach `attribute [local instance 2000] ...` if it states new
topological facts about the lift group, and should not `open` this module's
instances in a file that also elaborates against WordCohBridge's discrete ones.
