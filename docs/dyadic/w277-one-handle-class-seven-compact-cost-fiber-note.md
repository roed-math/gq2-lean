# W277 — the compact class-seven raw-cost fiber

W276 reduced the ordinary one-handle class-seven question to a finite set of compact packets.
W277 identifies the algebraic locus containing that set.

For every legal relative lift, its four compact factors form a depth-five unrestricted source.
Expanding the moved compact relator shows that the raw cost of this source is exactly the fixed
class-six defect.  Thus all attained compact packets lie in one affine fiber of the compact
raw-cost map.  Equivalently, the pointwise ratio of the raw sources associated to any two legal
packets lies in the raw-cost kernel.

The remaining finite ordinary obstruction is therefore not arbitrary packet dependence.  It is
the image of a single named compact kernel under the one-handle connecting construction.  This
wave does not prove that connecting image trivial or show that it reaches the reference
obstruction; either conclusion needs a new compatibility between compact kernel moves and the
one-handle relative row span.
