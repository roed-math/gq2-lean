# W236: parity-visible and primitive target directions

W235 reduces a target obstruction to six primitive mod-four directions or three even
directions. W236 identifies the even directions with the three explicit characters of the
mod-two coordinate plane.

An even direction detects a selected target exactly when that target's parity lies outside
the parity interaction range. Therefore every selected-coordinate failure splits exactly
into either a parity-visible obstruction or a genuinely primitive order-four obstruction.

This isolates the next front sharply: the parity branch is an ordinary two-dimensional
mod-two membership problem, while the primitive branch records genuinely second-order
information. Neither branch is asserted to vanish here.
