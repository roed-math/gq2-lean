# W243: literal certificates for failure of a balanced successor

W243 records the exact negative form of W242. At a relatively covered point, a literal CABD
detector is one of the three parity or six primitive scalar functionals which annihilates every
homogeneous CABD relation but does not annihilate the selected target coordinates.

The next balanced stage is empty exactly when every point of the current stage either lacks
ordinary relative coverage or carries one of these nine detecting certificates.

Consequently neither side of the remaining one-handle problem is opaque: a positive proof must
select a relatively covered point passing nine checks, while a negative proof must exhibit a
relative-coverage failure or a literal scalar detector at every available point.
