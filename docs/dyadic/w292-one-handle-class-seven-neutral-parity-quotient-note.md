# W292: class-seven neutral parity quotient

W290 produced a two-bit parity-plane surjection onto the standard class-seven neutral target.
W292 computes its kernel exactly: it is the range of
`oneHandleBalancedCoreNeutralityParityRow oneHandleStandardBalancedPoint 6`.

Consequently `oneHandleC7StandardNeutralityCokernelEquivParity` presents the neutral target as
the quotient of `(ZMod 2)^2` by the explicit standard parity-interaction row.  Lagrange gives
the exact cardinal identity

`|neutral target| * |parity interaction range| = 4`.

The target is trivial exactly when the parity row fills the whole two-dimensional plane.  No
such spanning statement is asserted here.  The remaining computation is now the rank of this
standard binary interaction row together with the image of the compact connecting kernel in
the resulting quotient.
