group-theoretic theorem, not an inference from the finite quotient calculation.

the cyclotomic orientation on every marked generator and has the universal `C + 2B` row.  The
single packet `oneHandleW4Mark_seed` records these static clauses together with the class-four
relation.

successor from this seed: either connect its finite target to the nine CABD compatibility checks,
