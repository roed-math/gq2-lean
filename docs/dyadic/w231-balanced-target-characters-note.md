# W231: characters need only kill the selected target

W229's three scalar rows force the entire finite neutrality cokernel to vanish. W230 shows
that only one target at one selected point is needed at each rung. W231 combines that sharper
quantifier with finite Pontryagin duality.

For a relatively covered point, the target lies in the constrained coordinate span exactly
when every complex additive character of its finite neutrality cokernel evaluates to one on
the obstruction class. Thus the target-character selectable supply is exactly equivalent to
the coordinate selectable supply and, in turn, exactly equivalent to nonemptiness of the next
balanced stage.

This is strictly target-sensitive: the cokernel may remain nontrivial, and no character row is
required to be surjective. Nothing here proves character vanishing. The remaining front is to
select one relatively covered point per rung whose particular obstruction is invisible to all
finite-cokernel characters.
