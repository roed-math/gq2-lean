# W245: a direct one-handle inverse limit

W245 removes the exact compact-automorphism fibre from the remaining one-handle Mpc problem.
A direct depth-`k` stage is now simply a six-letter marking in `D_M(2,1)` with the standard
handle pair, mod-two independence, the canonical cyclotomic rows, the universal `C + 2B` row,
and full relator depth `k`.

These stage sets are nested closed subsets of a compact function space.  W244 supplies the
fourth stage.  Nonemptiness at every finite depth therefore yields an exact topologically
generating marking and `MpcPivShiftH 2 1`.

The remaining theorem has the narrow interface `OneHandleDirectSuccessorSupply`: every direct
stage at depth at least four has a direct successor.  This formulation keeps the handle rows
fixed and leaves only the same four core slots used by the finite nine-CABD calculation.
