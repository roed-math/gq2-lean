# W232: exact pointwise character obstruction

W231 says that a relatively covered target lies in the constrained coordinate span exactly
when every complex additive character of its finite neutrality cokernel kills the obstruction.
W232 records the complementary statement: constrained coverage fails exactly when at least one
character detects that target.

This yields an exact description of successor failure. The next balanced stage is empty if and
only if every point in the current stage either already fails ordinary relative coverage or,
after relative coverage is chosen, has a character detecting its neutrality obstruction.

The result is diagnostic rather than negative. It constructs no uniform detecting character and
does not assert that a successor is empty. It isolates the precise finite, pointwise witness that
a counterexample would require and that a positive selection theorem must avoid.
