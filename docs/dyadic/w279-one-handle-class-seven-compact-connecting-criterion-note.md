# W279 — exact finite criteria for the compact connecting map

W278 showed that all dependence of the ordinary class-seven obstruction on the legal compact
lift factors through one compact-kernel connecting homomorphism.  W279 makes its vanishing an
explicit finite inclusion problem.

`OneHandleCompactKernelCovered` says that every direct level-six correction with zero forgotten
compact cost has relative shift in the four-row relaxed coordinate span.  This is equivalent to
`OneHandleCompactConnectingTrivial`, and also to containment of the full kernel-shift range in
that span.

Because the direct correction type is finite, the image of the connecting map is recorded as
the finite set `compactConnectingValues`.  The connecting map vanishes exactly when this set is
the singleton identity.  Thus the next unresolved ordinary statement is a finite range
inclusion—or equivalently a finite image computation.  Neither identity of the packet's
reference obstruction nor the separate neutral-C requirement is inferred here.
